# Fury Key System

A premium key generation and redemption system for Discord bots.

## Features
- Generate premium keys with `/keygen`
- Redeem keys with `/redeem`
- One-time use validation
- Premium role assignment on redemption
- SQLite tracking for keys and subscription expiry

## Install

```bash
pip install discord.py aiosqlite
```

## Required database table

```sql
CREATE TABLE IF NOT EXISTS users (
    user_id INTEGER PRIMARY KEY,
    expires_at INTEGER
);
```

## Quick start

```python
from key_system import ensure_key_tables, register_key_commands

await ensure_key_tables("database.db")

register_key_commands(
    bot,
    tree,
    "database.db",
    is_admin,
    make_embed,
    parse_duration,
    PREMIUM_ROLE_ID,
)
```

## Commands
- `/keygen <duration> [amount]` - create new keys
- `/redeem <key>` - redeem a key
- `/keys` - view recent keys

## Supported durations
- `1day`
- `3days`
- `7days`
- `3weeks`
- `1month`
- `1year`

## Example parser

```python
def parse_duration(duration):
    duration = duration.strip().lower()
    values = {
        "1day": 86400,
        "3days": 259200,
        "7days": 604800,
        "3weeks": 1814400,
        "1month": 2592000,
        "1year": 31536000,
    }
    return values.get(duration)
```

## Notes
- Keys are random uppercase alphanumeric strings.
- Keys are single-use and cannot be reused.
- Redeeming a key adds time to the user's existing premium expiry if present.
